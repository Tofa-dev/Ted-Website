## TED Website Portfolio Clone

A modern and responsive front-end website inspired by TED, designed to showcase talks, ideas, and content in a clean and engaging layout.

## Live Demo
https://tofa-dev.github.io/TedWebsite/

## About the Project

This project is a front-end clone inspired by the TED platform, which is known for sharing powerful talks on technology, entertainment, and design.

The goal of this project is to replicate a content-driven website with a focus on layout, structure, and user experience.

---

## Features

- Clean layout for showcasing talks/videos
- Fully responsive de3sign (mobile & desktop)
- Structured content sections
- Modern UI Styling
- Easy navigation across pages

  - CSS
